# digital-catalogue
Digital publication catalogue for Cambridge Publishing Company Pvt. Ltd.

## Verification

Run the complete local suite with Python 3 available as `python` (or set `PYTHON` to its executable):

```powershell
node scripts/run-tests.mjs
```

This runs the Node tests and the offline Publication Master preflight tests. Generated preflight reports remain local-only under `reports/publication-master-preflight/`.
